# Архипелаг — студия дизайна

Учебный проект «Разработка пользовательского Web-интерфейса», сделан по **собственному макету**. Идея взята из концептов «World Flip» на Awwwards: каждая услуга — это свой low-poly остров в 3D, а острова переворачиваются при переключении. В блоке связи способ связи тоже выбирается островом: кольцо поворачивается к нужному острову. «Архипелаг» — вымышленная студия.

## Структура

```
index.html               разметка
css/style.css            стили (mobile-first, брейкпоинты 600 / 1024 px)
js/islands.js            3D-детали (дома, деревья, маяк, вышка…) и сборка 8 островов
js/main.js               миры в шапке, кольцо островов связи, меню, аккордеон, форма
js/vendor/three.min.js   библиотека three.js r149 (MIT), лежит в проекте
video/clouds.mp4         фоновое видео шапки (облака, бесшовный цикл)
mockups/                 макеты для защиты: page.jpg, mobile.jpg, menu.png,
                         mobile-menu.png, worlds.jpg (4 мира), contact-islands.jpg (4 острова связи)
```

## Критерии задания

| Критерий | Где реализовано |
|---|---|
| Все блоки | шапка с мирами, «Путь проекта», вопросы, «Острова связи» с формой, футер |
| Мобильная версия | базовые стили для телефона; 3D-камера на телефоне отодвигается, чтобы острова помещались |
| Видео в шапке | `<video autoplay muted loop playsinline>` с облаками, окрашивается в цвет текущего мира (`mix-blend-mode`) |
| Выпадающее меню | «Миры» и «Острова связи»: по наведению и фокусу, CSS-transition (карточка падает с поворотом). Пункты сразу переключают мир или способ связи |
| Мобильное меню | синяя панель выезжает справа, пункты появляются по очереди (CSS-transition) |
| Шрифты | Oswald (заголовки) и Rubik (текст), Google Fonts |
| Слайдер | миры в шапке: стрелки, точки, свайп, стрелки клавиатуры; остров переворачивается, фон перекрашивается |
| Форма | `fetch` без перезагрузки; поле контакта меняется под способ связи (ник, e-mail, телефон, дата) и проверяется своим правилом; блокировка кнопки и спиннер, сообщение об ошибке, черновик в `localStorage` |
| JSLint | `js/main.js` и `js/islands.js` проходят без замечаний |

## Как работают острова

- **Остров** — три скруглённые плиты (`ExtrudeGeometry`) и набор low-poly деталей из простых фигур: коробок, конусов, цилиндров. Детали лежат в `islands.js`, каждый остров описан своей функцией в объекте `BUILDERS`.
- **Переворот мира** (шапка): старый остров кувыркается вперёд и уходит вниз, новый появляется снизу с пружинкой (`easeOutBack`), фон плавно меняет цвет (`@property --bg`).
- **Кольцо связи**: 4 острова стоят по кругу. При выборе способа связи кольцо поворачивается по кратчайшему пути, выбранный остров увеличивается, дальние опускаются вниз. На остров можно просто нажать мышкой (`Raycaster`).
- Обе сцены рисуются в одном цикле `requestAnimationFrame` и не рисуются, когда их не видно (`IntersectionObserver`).
- Если WebGL недоступен, остаются видео, тексты и форма. Если включено «уменьшение движения», анимации отключаются.

## Что поменять перед сдачей

1. **ID формы.** Замените `YOUR_FORM_ID` в `js/main.js` (строка 4) и в `action` формы в `index.html`.
2. **Макеты.** Переснимите `mockups/` у себя, когда загрузятся шрифты.
3. **Запуск.** Через Live Server или GitHub Pages. Если открыть файл двойным кликом, форма может не отправиться.
